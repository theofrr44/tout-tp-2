# Site vitrine — Tout-TP · Version "Le Plan"

Deuxième proposition de style pour le même site (mêmes contenus, direction
artistique différente). Statique en HTML/CSS/JS, prêt pour GitHub Pages.

## Différence avec la version "Le Chantier"
- **Le Chantier** (première version) : fond sombre asphalte, orange sécurité, police condensée façon signalétique de chantier, coupe de terrain animée en hero.
- **Le Plan** (cette version) : fond papier calque, encre bleu de plan, terracotta, police serif (Fraunces) façon document d'architecte, plan de parcelle coté + tampon circulaire "TOUT-TP" en hero, ligne graduée façon règle en séparateur de sections.

Les deux versions ont exactement la même structure de contenu (services,
méthode en 3 étapes, zone d'intervention, avis, contact) — seul le style
change, pour que le client choisisse l'identité visuelle qui lui plaît le
plus.

## Mettre en ligne avec GitHub Pages
Identique à la version 1 :
1. Dépôt GitHub avec `index.html`, `style.css`, `script.js` à la racine.
2. **Settings → Pages → Branch : main → `/root`** → Save.
3. Le site est en ligne après 1–2 minutes.

## ⚠️ Mêmes points à vérifier avant de vendre
- Services, zone d'intervention détaillée et horaires sont rédigés à partir
  d'entreprises de TP comparables du secteur : à faire valider par le
  patron de Tout-TP.
- SIRET et mentions légales laissés "à compléter" volontairement.
- Formulaire de contact à connecter sur [formspree.io](https://formspree.io) (remplacer `VOTRE_ID_FORMSPREE` dans `index.html`).
- L'illustration du hero est un plan de parcelle en SVG (100 % libre de droits) : à remplacer par de vraies photos/plans de chantier si possible.
